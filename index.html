Dual Envelope Routing Challenge

Mastering synthesis requires understanding that volume (Amplitude) and timbre (Filter) can move independently over time.

🎯 Mission: Create a "Pluck" sound. Set both Attacks to zero, use a short Filter Decay, and drop the Filter Sustain to zero.

1. Amplitude Envelope (VCA) - Controls Volume

2. Filter Envelope (VCF) - Controls Brightness
